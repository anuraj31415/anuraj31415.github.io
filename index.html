Things I've built

Three so far. All the code is public.

  • DeltaChecker

    Paste two texts, see what changed.

    A real-time text diff checker. You get unified or side-by-side views, and highlighting at character level inside changed lines, so you can see the one comma that moved. Ctrl+Enter compares, and there's a dark mode. The side-by-side view turns one flat diff into aligned rows, which is more bookkeeping than it sounds.

    Next.js 16 · TypeScript · Tailwind 4 · diff-match-patch

    source on GitHub → (DeltaChecker)

  • Typerator

    A 30-second typing test that reacts to your score.

    Minimal and distraction-free. The timer starts on your first keystroke, and WPM only counts correct characters. When time's up, a reaction clip plays from one of six tiers, bad to perfect, picked 60% by speed and 40% by accuracy. Under 40 WPM is a bad clip no matter how clean you typed. Harsh, but those are the rules. Esc restarts, and your last score stays in your browser. The scoring has unit tests, since WPM maths is exactly the kind of thing that's wrong in a quiet way.

    Next.js 16 · React 19 · TypeScript · Tailwind 4 · Vitest

    source on GitHub → (Typerator)

  • repo-pulse

    Your git history, summarised, from the terminal.

    A small Python CLI that reads a local repo and tells you commits per day, the most-changed files and who's been committing. --since takes anything git log does, and --json is there if you'd rather pipe it. No dependencies beyond git itself. The analysis code returns plain data and never prints, so the CLI is a thin layer on top. It reads filenames with -z, so awkward names don't break it. Tests run in CI on Python 3.9 to 3.12. The folder on my laptop is still called first-project.

    Python 3.9+ · stdlib only · pytest
